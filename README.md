# Golf Together

友達とラウンド情報・9ホールまたは18ホールのスコアを共有し、プレイヤーごとの推移や得意・課題ホールを振り返る Streamlit アプリです。日本語 UI、固定パスワード認証、SQLite 保存、任意の OpenAI による成長レポートに対応しています。

## 主な機能

- プレイヤーを登録し、ラウンド名・日付・ゴルフ場・各ホールのパーとスコアを記録（前半9ホール・後半9ホール・18ホールに対応）
- ラウンド一覧、ホール別スコアカード、ラウンド削除
- 18ホール換算平均、直近と初期の比較、スコア推移、得意・課題ホールを表示
- 個人分析ページで「総合スコア」「Par 3」「Par 4」「Par 5」「安定性」の5指標をレーダーチャートで可視化
- スコアから初心者・中級者・上級者の参考目安を表示（公式ハンディキャップではありません）
- OpenAI API キーを設定すると、選手ごとの比較や練習案を含む日本語レポートを生成

## Docker で起動

Docker と Docker Compose が使えるホストで、公開前に十分長くランダムな共有パスワードを `.env` に設定します。

```text
GOLF_APP_PASSWORD=replace-with-a-long-random-password
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

`.env` は Git に登録したり、公開したりしないでください。OpenAI のレポートを有効にする場合のみ `OPENAI_API_KEY` を設定します。アプリは `http://localhost:8501` で利用できます。

```bash
docker compose up --build -d
```

インターネットからアクセスさせるには、Docker ホストをインターネットに公開できる状態にし、ドメインと HTTPS を設定したリバースプロキシ（例: Caddy）から `localhost:8501` に転送してください。8501 番ポートを無条件に直接公開するのではなく、TLS とホスト側のファイアウォールを設定してください。`.env` の変更を反映するには `docker compose up -d` を再実行します。

ラウンドデータは Docker の名前付きボリューム `golf_data` に保存され、コンテナ再作成後も保持されます。ホスト障害に備え、運用先の手順に従ってこのボリュームを定期バックアップしてください。

## Streamlit Community Cloud

GitHub にアプリを配置して Community Cloud から `app.py` をデプロイする場合、アプリの設定画面の **Secrets** に以下を登録します。

```toml
GOLF_APP_PASSWORD = "十分に長いランダムな共有パスワード"
OPENAI_API_KEY = "OpenAIのAPIキー"
OPENAI_MODEL = "gpt-4o-mini"
```

このアプリの標準 SQLite ファイルはローカルディスクにあります。Community Cloud のローカルファイルは永続ストレージではないため、この構成を使う場合は再起動・再デプロイで記録が失われる可能性があります。永続保存が必要な公開運用では、上記 Docker 構成を永続ボリューム対応のホストで使用してください。

## 認証・AI に関する注意

- 認証はアプリ全体で共有する単一パスワードです。ユーザー別アカウントや権限管理はありません。パスワードは環境変数 `GOLF_APP_PASSWORD` または Streamlit secrets に設定します。
- AI レポートを実行すると、選択したプレイヤー名と集計スコアが OpenAI API に送信されます。ニックネームを使用し、送信内容を理解したうえで実行してください。API キーがなくても統計ベースのレポートは利用できます。
- プレイヤーのレベル目安は登録済みラウンドの平均オーバーパーによるアプリ独自の分類です。ラウンドが少ない場合やコース難易度が異なる場合には特に、実力を断定するものではありません。
- 9ホールと18ホールの記録は1ホール当たりで集計し、平均スコアと推移は18ホール換算（1ホール当たりの平均を18倍）の参考値として表示します。
- レーダーチャートはスコア記録のみから作る独自指標です。総合・Par別指標は平均対パー差、安定性は各ホールの対パー差のばらつきから算出し、ショットやパットの技術を直接測るものではありません。記録のないPar区分がある間はチャートを表示しません。
